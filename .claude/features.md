# 核心功能与设计方案

## 1. 混合信息流 (Hybrid Feed)
项目最核心的功能是在一个时间线内合并展示 Twitter (X) 和雪球的动态。
- **排序逻辑**: 统一使用 `createdAt` 时间戳进行倒序排列。
- **来源感知**: `TweetCard` 组件通过识别 `source` 字段，为雪球帖子展示 ❄️ 图标，为 Twitter 展示原站链接。
- **无缝跳转**: 点击推文直接跳转至对应平台的原始页面。

## 2. 推文同步机制 (Background Sync)
采用分布式轮询策略，避免触发 API 速率限制：
- **Twitter 同步**: 每 2 分钟执行一次。同时抓取关注人列表 (Following) 和特定监控用户。
- **雪球同步**: 每 5 分钟执行一次。抓取监控用户历史和雪球首页 Feed。

## 3. 内容过滤系统
为了净化阅读体验，后端实施了以下过滤层：
- **语言检测**: 
  - 日语: `[\u3040-\u309F\u30A0-\u30FF]` (平假名/片假名)
  - 韩语: `[\uAC00-\uD7AF\u1100-\u11FF\u3130-\u318F]` (谚文)
- **重复过滤**: 基于数据库唯一索引防止重复显示。

## 4. Query ID 管理 (X.com 专有)
针对 X.com 动态变化的 GraphQL Query ID，提供了三重保障：
- **自动检测**: 后端具备尝试从 X.com 流量中自动嗅探新 Query ID 的能力。
- **手动覆盖**: 提供设置面板，允许用户在自动失效时手动填入最新的 ID。
- **持久化**: ID 存储在数据库中，修改后立即生效。

## 6. 媒体与内容展示
| 类型 | 处理方式 | 备注 |
|------|----------|------|
| 图片 | 本地预览 + Lightbox | 拼接 `?name=small` 优化加载 |
| 视频 | 跳转原站 | 规避 referer 与 cookie 限制 |
| 链接 | 自动激活 HTML 链接 | 后端正则解析 |
| 文章 | 特殊卡片展示 | 支持 x.com/i/article 格式 |
