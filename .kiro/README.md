# Kiro Configuration

This directory contains Kiro-specific configuration and resources for this project.

## Directory Structure

- `skills/` - Project-level skills (reusable capabilities and knowledge)
- `steering/` - Steering files (guidelines and workflows)
- `settings/` - Project settings (e.g., mcp.json for MCP server configuration)
- `specs/` - Spec files (requirements, design, and task documents)

## Usage

- **Skills**: Add custom skills to enhance Kiro's capabilities for this project
- **Steering**: Define project-specific guidelines and best practices
- **Settings**: Configure MCP servers and other project settings
- **Specs**: Create structured specifications for features and bugfixes
